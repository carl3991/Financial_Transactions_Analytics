
### Key Findings


- Logistic Regression struggled to classify transaction types effectively, even after addressing class imbalance.
- XGBoost achieved strong predictive performance with 95.7% accuracy, achieving a Credit transaction recall of 81% and a Debit transaction recall of 100%.
- Random Forest achieved perfect classification performance on the synthetic dataset.
- Tree-based ensemble models significantly outperformed Logistic Regression, indicating that transaction type is driven by complex nonlinear relationships among customer and transaction attributes.
